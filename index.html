Este navegador no puede abrir el tablero

El tablero corre entero dentro del navegador, y para eso necesita una pieza que en el tuyo no esta funcionando: los service workers. Sin ella la aplicacion no se puede servir a si misma y la pagina termina en un error 404.

Safari: en el menu Desarrollo, desmarca «Desactivar service workers». Si no ves ese menu, activalo en Ajustes › Avanzado › «Mostrar funciones para desarrolladores web». En ventana privada no funcionan nunca: usa una ventana normal.

Si no es eso: borra los datos de este sitio -Ajustes › Privacidad › Gestionar datos de sitios web, buscar «mebucca»- y recarga. Puede haber quedado una version vieja guardada. Tambien conviene desactivar bloqueadores de contenido aqui.

Si nada de eso resulta, el tablero abre sin configurar nada en Chrome o Edge.
